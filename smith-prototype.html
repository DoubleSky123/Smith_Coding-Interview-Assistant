📋 summarize_orders(orders) — task spec

Function signature

def summarize_orders(orders: list[dict]) -> dict:

Each order contains

  • customer — string, the customer's name
  • status — "completed" or "cancelled"
  • amount_cents — non-negative integer

Return

A dict mapping customer names to their total completed-order amount. Ignore cancelled orders. Customers with only cancelled orders must not appear in the output.

Examples

# Empty input
summarize_orders([]) == {}

# Cancelled orders ignored
summarize_orders([
    {"customer": "Alice", "status": "cancelled", "amount_cents": 500}
]) == {}

# Multiple completed orders — same customer
summarize_orders([
    {"customer": "Alice", "status": "completed", "amount_cents": 300},
    {"customer": "Alice", "status": "completed", "amount_cents": 200},
]) == {"Alice": 500}

# Multiple customers
summarize_orders([
    {"customer": "Alice", "status": "completed",  "amount_cents": 1000},
    {"customer": "Bob",   "status": "completed",  "amount_cents":  750},
    {"customer": "Alice", "status": "cancelled",  "amount_cents":  200},
    {"customer": "Carol", "status": "cancelled",  "amount_cents":  400},
]) == {"Alice": 1000, "Bob": 750}
